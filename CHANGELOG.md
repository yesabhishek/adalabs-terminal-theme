# Changelog

## 2.0.0

- **Twenty named themes**: 10 dark (Obsidian, Carbon, Slate, Ink, Graphite, Espresso, Moss, Plum, Abyss, Dusk) and 10 light (Snow, Paper, Linen, Sepia, Mist, Cloud, Sage, Blush, Lavender, Stone). These replace the numbered Dark 1–5 and Light 1–5 shades.
- Each theme has its own surfaces, accent, syntax hues and terminal ANSI colors, generated from a single palette. The workbench, terminal and code always match.
- Much wider coverage: bracket-pair colorization, symbol and outline icons, command center, sticky scroll, inlay hints, merge editor, SCM graph, debug tokens, testing, notebooks, chat and inline chat, settings, and charts.
- Richer syntax scopes: decorators, doc tags, Rust lifetimes, JSX components, CSS selectors and values, YAML/TOML keys, shell, and Markdown links and lists.
- Automated WCAG contrast audit for every palette (`npm run check`).
- New die-cut sticker icon.

## 1.1.0

- Replaced the six branded dark variants with ten shade-based themes (AdaLabs Dark 1-5 and Light 1-5).

## 1.0.0

- Initial release as **AdaLabs Terminal**.
